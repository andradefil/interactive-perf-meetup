# Interactive Performance Analysis in the JVM Meetup

This repo contains Clojure code used during the presentation of the
meetup for the Clojurehackers group in Campinas on October 31st, 2026
to demonstrate a case study of performance while creating programs
interactively in the Clojure REPL.

This repo aims to provide practical examples helping to explore some
mechanics of the language in terms of performance. By observing how
the application evolves, we can learn to explore the contents of the
JAR, build the classpath, analyze the dependency tree, configure
threads, understand memory allocation, and work with networking in
Clojure programs.
